403 Forbidden

Validasi Keamanan CSRF Gagal

Token CSRF tidak valid atau sesi telah kedaluwarsa.

Apa yang terjadi?
Sistem mendeteksi bahwa request ke {{ path or 'endpoint' }} dikirim tanpa token keamanan anti-pemalsuan (CSRF Token) yang valid.

Penyebab umum:
  • Formulir dibuka terlalu lama sehingga sesi token kedaluwarsa.
  • Cookie sesi Anda terhapus saat mengisi formulir.
  • Permintaan dikirim dari domain luar / serangan Cross-Site Request Forgery.
